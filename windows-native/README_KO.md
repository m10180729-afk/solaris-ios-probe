# Solaris 1.0 Windows

설치 파일을 실행하거나 포터블 ZIP 전체를 풀고 `SolarisNativeHost.exe`를 실행하세요. 동봉한 `ffmpeg.exe`가 같은 폴더에 있어야 하며 WebView2가 필요합니다.

Google 계정으로 로그인하고 친구 대화나 서버 채널에서 **화면공유 시작**을 누르세요. 상대방의 추가 수락 없이 같은 대화·채널에 화면이 표시됩니다. GPU 인코딩을 우선 사용하며 지원되지 않는 PC는 CPU 호환 모드로 전환합니다. 목표는 1080p·60fps이며 실제 출력은 PC와 네트워크 성능에 따릅니다. 시스템 재생 소리를 공유하며 마이크·음성통화는 없습니다.

시청자는 공유 화면을 확대·축소하거나 시청을 중지할 수 있습니다. 시청자 이동만으로 송출이 꺼지지 않으며 실제 서버 연결 손실은 제한된 복구 후 종료합니다. 연결 상태에서 송신·수신 측정값과 진단을 확인하세요.

최소화·최대화·크기 조절 및 F11 전체화면, Escape 복원을 지원합니다. 설정에서 프로필 ID·접속 상태·로그아웃·회원 탈퇴를 관리합니다. 자세한 내용은 `docs/SOLARIS_1_0_KO.md`를 참고하세요.

현재 패키지에는 배포용 코드 서명 인증서가 적용되지 않았습니다. 실제 기기 화면 캡처·Google 복귀·GPU 성능 확인은 자동 시험과 별도로 필요합니다.
