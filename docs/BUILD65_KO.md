# Solaris 0.4.0 build65

Windows·iOS/iPadOS는 송신과 수신을 지원하고 Android는 화면공유 시청 전용이다. Android 화면 캡처 서비스·권한·송신 코드·네이티브 WebRTC AAR을 제거했다. 파일 전송과 계정 기능은 유지한다.

공유 화면은 휠·트랙패드와 두 손가락으로 50–400% 확대·축소하고 확대 상태에서 끌어 이동한다. 100% 버튼과 두 번 누르기로 화면 맞춤을 복원한다. iPad 네이티브 전체화면도 같은 확대 범위를 지원한다. 전체화면/종료 표기를 실제 상태와 맞추고 Windows OS 창 버튼과 앱 버튼의 중복을 제거했다.

연결 실패·인터넷 끊김·장시간 신호 단절 시 화면공유를 종료한다. 마지막으로 연결됐던 시청자가 모두 끊기면 짧은 유예 후 캡처도 종료한다. 아직 첫 시청자가 없는 방송은 허용한다. 화면을 바꾸면 이전 시청을 정리한다. 늦게 완료된 채널 이동은 새 DM/서버 선택을 덮어쓰지 않는다.

송신 인코딩/전송 측정과 수신 디코딩/재생 측정을 따로 표시한다. 지원되는 웹 수신 경로는 실제 제시된 프레임 간격으로 하위 1% FPS를 측정한다. 네트워크 왕복 지연만으로 어느 쪽 인터넷이 원인인지 단정하지 않는다. 순간 프레임 드롭의 실기기 원인과 GPU/네트워크 성능은 아직 별도 시험이 필요하다. 고정 60fps 캡처 정책과 원본 H264/RTP 핵심을 유지하고 UI 확대가 원본 송출 해상도를 변경하지 않는다.

Google 또는 이메일을 인증한 ID+비밀번호로 가입/로그인한다. 이메일은 인증·복구용이다. 내 프로필에서 ID를 변경할 수 있고 UID·친구·서버 관계를 유지한다. 기존 ID는 로그인 조회에서 제외된다. 접속 상태는 온라인·자리비움·방해금지·숨김을 선택하며 숨김은 다른 사람에게 오프라인으로 표시된다. 다른 기기의 온라인 상태를 유지하고, 종료/통신 단절 후 남은 접속 상태는 45초 유효기간으로 만료된다. Windows 최소화는 종료로 취급하지 않는다.

서버의 모든 멤버가 동일한 초대코드를 복사할 수 있다. 소유자의 이름·채널 관리 권한은 그대로 제한된다. 네이티브 앱에서도 복사 버튼이 작동하도록 플랫폼 클립보드 기능을 연결한다. 제공된 은하 이미지로 Windows·Android·iOS 앱 아이콘과 앱 내 로고를 교체한다.

본인 탈퇴는 ID 확인 후 계정과 소유 서버·채널, 친구·DM·공유 상태 및 아바타를 삭제한다. 서버가 확인한 본인 UID만 삭제할 수 있다. 토큰이 남아 있어도 삭제/탈퇴 중인 계정이나 폐기된 세션은 RPC와 아바타 접근이 거절된다. 정리 중 오류는 같은 계정으로 다시 시도할 수 있다. 서비스 키는 서버 Edge Function에만 있으며 클라이언트에 포함하지 않는다.

사용자가 승인한 기존 테스트 데이터 초기화는 2026-10-13에 실행했다. 계정 11개·프로필 10개·소유 서버 2개·채널 3개·DM 2개와 관련 인증/관계 데이터를 삭제했고 잔여 계정·프로필·세션·서버·채널·DM이 0개임을 확인했다. 기존 계정으로는 로그인할 수 없으며 새로 가입해야 한다.

서버: `backend/005_build65_accounts_presence_invites.sql`과 동일한 관리형 마이그레이션, `solaris-account` Edge Function이 Solaris test에 배포됐다. ID 로그인은 아직 사용자 JWT가 없어서 게이트웨이 JWT 검사를 끄지만, 탈퇴 경로가 Auth getUser와 살아 있는 auth.sessions를 직접 검증한다. 서버 전용 서비스 RPC는 anon/authenticated 역할의 실행 권한을 거부한다.

익명 가입은 서버 설정에서도 비활성화했다. 일반 이메일 가입·복구는 Custom SMTP 설정과 실제 메일 도착 확인이 필요하다. Supabase 기본 발송은 프로젝트 팀원 주소로 제한된다. Gmail SMTP는 현재 소규모 테스트용으로 설정할 수 있지만, 정식 출시 전 인증 메일 전용 발송 서비스로 변경하고 발송량·도메인 인증을 준비한다.

실제 배포된 서버에서 임시 검증 계정으로 ID·비밀번호 로그인, ID 변경 후 같은 UID 유지·이전 ID 로그인 거부, 로그아웃 후 남은 JWT의 RPC 거부, 본인 탈퇴, 탈퇴 후 JWT·ID 로그인 거부를 확인했다. 검증 계정·프로필·소유 서버·세션도 모두 0개로 정리됐다. 이 검사는 이메일 도착이나 실기기 Google 로그인을 증명하지 않는다.

iPad IPA는 App Groups를 포함해 재서명한다. Android 테스트 APK의 CI debug 서명이 이전 설치본과 다르면 덮어쓰기 업데이트가 거절될 수 있다. 이 빌드는 출시 준비용 검토판이며 main 병합·스토어 제출·공식 릴리스는 수행하지 않는다.
