## 운영 전 조건

- 이번 SQL을 운영 DB에 자동 적용하지 않았습니다. 소유자가 SQL Editor에서 `backend/001_solaris.sql`을 한 번 적용하고 익명 Auth를 활성화해야 합니다. 기존 build54 테이블은 삭제하지 않습니다.
- ReplayKit 인증 전달은 보호된 공통 App Group을 사용합니다. 해당 권한이 앱/확장의 실제 재서명 프로필에서 유지되는지 검증해야 합니다. 권한이 없으면 공유를 명시적으로 거부합니다.
- STUN만으로 모든 NAT를 통과할 수 있다는 보장은 없습니다. 필요한 TURN 중계와 오프라인 파일 보관은 무료 P2P와 별도 비용입니다.
- OS가 모바일 앱을 정지시킨 동안 계속 송수신을 보장하지 않습니다. 부분 파일과 기록을 보존해 가능한 범위에서 이어받습니다.
- 서버 관리 RPC는 프로그램 릴리스 권한을 부여하지 않습니다. Actions는 테스트 파일만 생성하고 정식 릴리스를 자동 게시하지 않습니다.
