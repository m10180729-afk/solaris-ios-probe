# 집에서 실행하는 순서

**예상 경로일 뿐, 이 환경에서 IPA 빌드·설치까지 성공한 절차로 검증한 것은 아닙니다.**
오류가 나오면 해당 단계에서 멈추세요. 보안 기능을 전부 끄거나 유료 인증서를 구매하지 마세요.
처음에는 친구가 없어도 됩니다. 내 iPad와 내 Windows PC를 같은 공유기에 연결해 시험합니다.

## 0. 먼저 결정할 것: 소스 공개 여부

Mac 대신 GitHub의 컴퓨터에서 iOS 앱을 빌드합니다.

- 공개 저장소: 표준 macOS 러너 실행은 무료. 코드·첨부 로고가 인터넷에 공개됩니다. 친구 전용 서비스여도 소스 공개는 별개의 결정입니다.
- 비공개 저장소: 계정의 무료 사용량 범위에서만 실행하세요. 한도·결제 정책 확인 없이 실행하지 마세요.
- 이 프로젝트는 어떤 저장소도 만들거나 업로드하지 않았습니다. 공개에 동의하지 않으면 공개 저장소로 진행하지 마세요.
- 결제수단을 새로 등록하거나 유료 실행 환경을 선택할 필요가 없습니다. 무료 조건을 확인할 수 없으면 중단하고 질문하세요.

## 1. PC에 압축 풀기

1. ZIP을 Windows의 원하는 폴더에 압축 해제합니다. SSD에서 실행해도 됩니다.
2. 압축을 푼 `Solaris-iOS-Probe` 안에 `README.md`, `ios`, `receiver`, `scripts`가 있는지 확인합니다.
3. Windows 터미널에서 이 폴더를 열어 둡니다. 파일 탐색기 주소창에 `powershell`을 입력하면 해당 위치에서 열 수 있습니다.

## 2. GitHub에 소스 올리고 빌드하기 — 공개/요금 조건 확인 후

계정 생성과 업로드는 본인이 선택해 진행하는 외부 작업입니다. 대신 진행을 원하면 먼저 저장소 공개 여부와 업로드·빌드 실행을 승인해야 합니다.

1. 원하는 공개 설정으로 새 빈 저장소를 만듭니다. 저장소 이름 예: `solaris-ios-probe`.
2. `Add file → Upload files`에서 **압축파일 자체가 아닌 프로젝트 폴더 안의 내용**을 업로드합니다.
3. 저장소 최상단에 `ios/project.yml`, `scripts/build_ios.sh`가 보이는지 확인합니다. `Solaris-iOS-Probe/ios/...`처럼 바깥 폴더가 한 겹 더 들어가면 빌드 경로가 틀립니다.
4. `.github/workflows/build-ios-probe.yml`도 반드시 포함해야 합니다. 폴더가 업로드되지 않으면 GitHub의 `Add file → Create new file`에 이 경로를 넣고, 동봉된 YAML 내용을 그대로 붙여 넣습니다. 파일 이름에 마침표가 있습니다.
5. 저장소의 `Actions → Build Solaris iOS Probe → Run workflow`를 누릅니다. 이 수동 동작 전에는 빌드가 시작되지 않습니다.
6. 성공한 실행의 아래쪽 `Artifacts`에서 `SolarisProbe-resign-required`를 다운로드합니다.
7. 다운로드한 결과물 ZIP 안의 `SolarisProbe-resign.ipa`를 꺼냅니다.

이 IPA는 **로컬 재서명 후보 파일**입니다. Apple 개발자 서명이나 설치 허가를 받은 파일이 아닙니다.
빌드는 계정 비밀번호 없이 수행합니다. 실제 무료 계정 서명은 다음 단계에서 내 PC로 진행합니다.
빌드 결과물은 3일 보관하도록 설정했습니다. 소스는 저장소에 남습니다.

### 빌드가 빨간색으로 실패하면

실패한 작업의 첫 번째 `error:` 주변만 복사해 전달하세요. 로그에 개인 정보가 없는지 먼저 확인합니다.
작업 이름도 알려 주세요: `Validate source`, `Test shared configuration`, `Build and package` 중 어디인지가 중요합니다.
서명 인증서 업로드, Team ID 입력, 유료 개발자 가입으로 임의로 해결하려 하지 마세요.

## 3. iPad에 설치 시도

AltStore Classic은 무료 서명을 시도할 후보입니다. 본체 앱 설치와 ReplayKit 확장 작동은 별도로 확인해야 합니다.
아래 절차의 운영체제 호환성은 실제 기기 결과로 판단합니다.

1. [AltStore Windows 공식 안내](https://faq.altstore.io/altstore-classic/how-to-install-altstore-windows)를 엽니다. 설치 파일은 공식 출처에서만 받으세요.
2. 안내에 따라 AltServer와 필요한 Apple 구성 요소를 준비합니다. 안내는 Apple 배포 iTunes/iCloud를 기준으로 하며, Store 버전을 이미 쓰는 경우 공식 대체 절차를 확인하세요. 기존 프로그램을 무작정 삭제하지 마세요.
3. USB 데이터 케이블로 iPad와 PC를 연결하고, 본인 PC인지 확인한 뒤 기기의 신뢰 절차를 진행합니다.
4. AltServer에서 iPad에 AltStore를 설치합니다. Apple 계정 입력은 공식 설치 도구에서 직접 합니다. 비밀번호·2단계 인증번호를 채팅에 보내지 마세요.
5. 필요한 경우 기기의 개발자 모드 및 본인 개발자 프로필 신뢰 절차를 공식 안내대로 진행합니다. 메뉴가 없으면 현재 오류를 알려 주세요.
6. IPA를 iPad의 파일 앱으로 옮긴 뒤 AltStore의 `My Apps → +`에서 선택합니다. PC의 AltServer가 켜져 있어야 합니다.
7. **앱 확장을 유지하는 옵션을 선택합니다.** `Remove App Extensions`처럼 확장을 제거하는 선택은 하지 마세요. 방송 확장이 삭제되면 화면공유를 시험할 수 없습니다.
8. 설치한 `Solaris Probe`를 엽니다. `확장: ...broadcast...` 표시와 `App Group 후보`가 있는지 확인합니다.

`App Group 없음`, 설치 불가, 확장 누락이 나오면 멈추고 오류 문구를 알려 주세요. 권한 제한을 우회한 인증서나 기기 탈옥은 이 계획에 포함되지 않습니다.
무료 서명은 만료 전에 갱신해야 합니다. 정확한 남은 기간은 AltStore에서 확인하고, 갱신 뒤 확장도 다시 시험합니다.

## 4. Windows 수신기 시작

1. [Python 공식 사이트](https://www.python.org/downloads/windows/)에서 지원되는 Python 3 버전을 설치합니다. 코드는 3.10 이상을 대상으로 하며 별도 패키지 설치는 없습니다.
2. 프로젝트 폴더의 PowerShell에서 다음 명령을 실행합니다.

```powershell
py -3 --version
ipconfig
```

3. 현재 연결된 Wi-Fi/이더넷의 `IPv4 주소`를 찾습니다. `192.168...`, `10...`, `172.16~31...` 같은 집 내부 주소입니다. 가상 어댑터/VPN 주소와 혼동하지 마세요.
4. 아래 예시의 IP를 **내 PC의 주소로 바꾸고** 실행합니다.

```powershell
py -3 receiver/receiver.py --bind 192.168.0.10
```

`py` 명령이 없다면 Python 설치가 인식되는지 먼저 확인하세요. `python --version`이 3.10 이상을 표시한다면 위 명령의 `py -3` 대신 `python`을 쓸 수 있습니다.

5. 수신기가 표시하는 주소와 64자리 임시 토큰을 확인합니다. 이 토큰은 수신기를 다시 시작하면 바뀝니다.
6. 내 PC 브라우저에서 표시된 주소를 열고 토큰을 붙여 넣은 뒤 `미리보기 연결`을 누릅니다.
7. Windows 방화벽이 묻는다면 **신뢰하는 집의 개인 네트워크에 한해서** 필요한 접근을 허용합니다. 전체 방화벽을 끄지 마세요. 공유기 포트포워딩도 하지 않습니다.

터미널은 계속 열어 둡니다. PC 브라우저 주소와 iPad의 PC 주소는 동일합니다. `localhost`나 `127.0.0.1`은 iPad에서 PC로 연결하는 주소가 아닙니다.

## 5. iPad에서 방송 시작

1. PC와 iPad를 같은 집 네트워크에 연결합니다. PC가 유선이어도 같은 공유기면 가능합니다. 게스트 Wi-Fi의 기기 간 차단이 있으면 연결되지 않을 수 있습니다.
2. Solaris Probe에 PC 주소와 임시 토큰을 입력합니다.
3. `설정 저장 · PC 연결 확인`을 누르고 로컬 네트워크 권한을 허용합니다.
4. `앱의 App Group 읽기/쓰기 성공`, `PC 연결 성공`이 뜨는지 확인합니다.
5. 앱 안의 Apple 방송 버튼을 직접 누르고 방송 시작을 선택합니다. 마이크는 처음에는 꺼도 됩니다.
6. 알림이 보이지 않도록 집중 모드를 켜고, 민감한 내용이 없는 앱으로 이동합니다. PC에 화면이 오는지 확인합니다.
7. 가로·세로 회전, 다른 앱 전환, 10분 유지, 방송 종료 후 재시작을 순서대로 시험합니다.
8. iPhone도 검증하려면 iPad 방송을 먼저 종료하고 3초 이상 기다린 후 같은 절차로 시험합니다. 동시에 두 기기를 송출하지 않습니다.

검은 화면인 앱 하나만으로 실패라고 판단하지 마세요. 보호된 영상 등은 캡처가 제한될 수 있습니다. 먼저 직접 만든 메모처럼 민감하지 않은 일반 화면으로 확인합니다.

## 6. 종료와 결과 전달

1. iPad의 시스템 방송 표시/방송 버튼으로 **방송을 직접 종료**합니다.
2. PC 화면이 약 3초 후 비워지는지 확인합니다.
3. PC 수신기 터미널에서 `Ctrl+C`를 누릅니다.
4. `docs/DEVICE_TEST_KO.md` 양식대로 결과를 알려 주세요. 토큰과 계정 정보는 빼고 전달합니다.

이 과정이 성공해도 인터넷 통화·1080p60·음성 동시 전송은 아직 성공한 것이 아닙니다. 이후 2단계부터 확인합니다.

## 증상별 우선 확인

| 증상 | 확인 |
| --- | --- |
| iPad 설치 자체 실패 | 오류 문구, 무료 계정의 앱/App ID 한도, 확장 포함 여부 |
| App Group 없음/저장 실패 | 재서명 후 앱·확장의 App Group 권한; 삭제/유료 전환 전에 결과 공유 |
| 방송 목록에 Solaris 없음 | 방송 확장을 제거하지 않았는지, 빌드에 포함됐는지 |
| PC 연결 실패 | PC IP, 같은 네트워크, 개인 네트워크 방화벽, iPad 로컬 네트워크 권한 |
| 방송 직후 종료 | 확장에서 설정 읽기 실패 여부, 시스템 오류 문구 |
| HTTP 401 | 수신기 재시작으로 바뀐 토큰을 앱과 브라우저에 다시 입력 |
| HTTP 409 | 다른 기기 방송을 멈추고 3초 이상 기다리기 |
| FPS가 5 이하 | 이번 미리보기 상한. 1080p60 성능 판단에 사용하지 않기 |
| 캡처 FPS 0 또는 낮음 | 화면이 정적인지 확인. 움직이는 내용으로 다시 관찰; 고정 60fps 보장 아님 |
