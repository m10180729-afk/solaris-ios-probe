# Solaris 1.0

Windows·Android·iPhone·iPad에서 Google로 계속하기를 눌러 가입하고 로그인합니다. 첫 가입 때 닉네임과 검색용 ID를 정합니다. 설정에서 프로필 ID·접속 상태를 바꾸고 로그아웃하거나 회원 탈퇴할 수 있습니다.

서버를 선택하면 채널과 참여자가 보입니다. 서버에 가입한 멤버는 초대 링크를 복사할 수 있습니다. 친구와 개인 메시지를 주고받고 일반 파일을 전송할 수 있습니다. 일반 파일 한도는 100MiB입니다.

Windows와 iPad에서 화면공유를 송출합니다. Android는 공유 화면을 받는 기능을 제공합니다. 상단의 ‘화면공유 시작’을 누르면 친구 대화나 현재 채널에 내 화면이 표시되며 상대방의 추가 수락은 필요하지 않습니다. 같은 대화·채널에서 공유 중인 화면은 자동으로 연결되고 시청 중지·다시 시청을 선택할 수 있습니다. iPad에서는 iPadOS의 화면 기록 시작 확인이 필요합니다. 공유 화면의 확대·축소와 이동은 마우스 휠·터치 동작으로 조절합니다. 연결 진단은 송신 처리·수신 처리·네트워크 경로를 구분해 보여 주며, 측정되지 않은 항목은 정상으로 추정하지 않습니다.

한 시청자의 연결 오류는 다른 시청자와 전체 송출에 영향을 주지 않도록 처리했습니다. 시청자가 잠시 빠지거나 다른 대화로 이동해도 송출은 유지되며, 본인이 중지하거나 실제 서버·인증 연결이 끊기면 종료합니다. 느린 영상 처리·통계 조회와 서버 동기화가 방송·시청 유지 신호를 막지 않도록 분리했습니다. iPad에서는 백그라운드 방송과 인증 갱신이 중지하거나 교체한 방송을 다시 만들지 않도록 보호했습니다. 종료 진단은 유지 신호 시간 초과·서버 종료·시스템 확장 중단을 구분합니다.

Windows는 GPU 인코딩을 우선 사용하며 지원되지 않는 PC에서는 CPU 호환 H.264 모드로 전환합니다. 목표 출력은 1080p·60fps이며 실제 출력은 CPU·GPU·네트워크 성능에 따릅니다. Android는 시스템 상태·내비게이션 바와 키보드 바깥에 앱 화면을 배치합니다. iPad 키보드는 전체 앱을 밀어 올리지 않고 채팅 영역의 높이를 조절합니다.

Windows 설치 파일과 앱 창, Android 앱 버전, iPad 앱 정보와 파일 이름은 Solaris 1.0으로 표시합니다. 예전 개발 빌드 번호는 일반 화면에서 표시하지 않습니다. 설치 업데이트를 식별하는 플랫폼 내부 버전 코드는 유지합니다.

Android 배포 APK에는 계속 사용할 개발자 서명 키를 사용합니다. 이전 테스트 APK와 서명이 다르면 기존 테스트 앱을 삭제한 뒤 설치해야 합니다. 서버 데이터는 보존되지만 기기에만 저장한 기록과 미완료 파일은 삭제 전에 정리하세요. 이후 Solaris 배포 APK는 같은 서명 키로 업데이트해야 합니다. 이 키는 PC의 보호된 작업 폴더에 보존하며 배포 ZIP과 소스 저장소에 포함하지 않습니다.

iPad IPA는 사용자의 설치 방식에 맞는 서명과 App Groups 설정이 필요합니다. 이 파일 자체가 App Store 승인이나 배포를 의미하지 않습니다. Windows 설치 파일의 배포 인증서 적용과 물리 기기에서의 Google 복귀·GPU·네트워크 품질·ReplayKit 확인은 자동 컴파일·연결 시험과 별도로 확인합니다. 다운로드 파일의 최종 검증 결과와 해시는 별도 배포 안내에 기록합니다.
