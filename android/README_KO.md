# Solaris Android 수신 · build53

GitHub Actions의 `Solaris-Android-Receiver-build53-debug` artifact에서 APK를 받아 갤럭시 폰에 설치합니다. 별도 Moonlight/Apollo는 필요하지 않습니다. Windows 송신 화면은 **Windows 화면 받기**, iPad 송신 화면은 **iPad 화면 받기**를 누릅니다. 송신기와 방 ID가 같아야 합니다. 이 APK는 화면을 보내지 않으며 마이크 권한도 사용하지 않습니다.

Android System WebView를 최신 상태로 유지하세요. 화면 수신 중에는 앱을 켜 두세요. 진단은 수신 화면의 **진단 복사**를 누릅니다. 복사가 허용되지 않으면 표시되는 텍스트 상자를 선택해 복사하세요. 빌드 성공 뒤 실제 Galaxy에서 H.264 영상과 스테레오 소리를 검사해야 합니다.
