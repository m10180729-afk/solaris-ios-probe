# Solaris Android · build63 인증 수정본

build63은 기기 복귀 후 인증 오류가 대기로 남는 문제를 수정합니다. 현재 인증 처리와 계정 연결 안내는 [build63 인증 수정](../docs/BUILD63_AUTH_KO.md)을 확인하세요. 아래 공유/설치 안내는 build62에서 이어집니다.

화면공유 송신·수신과 파일 전송을 포함한 ARM 기반 Android 11 이상 휴대폰용 테스트 앱입니다. APK에는 `arm64-v8a`·`armeabi-v7a`를 포함합니다. 친구와의 화면공유 세션 또는 서버 채널에서 사용합니다. 음성 대화는 Discord를 사용하며 Solaris는 마이크를 요청하지 않습니다.

화면공유 시작에는 매번 Android 시스템 승인이 필요합니다. Android 14 이상에서는 승인 창에서 **전체 화면** 또는 **공유할 앱**을 선택합니다. 다른 앱으로 이동하면서 화면을 공유하려면 전체 화면을 선택하세요. 앱 하나만 선택하면 다른 앱이나 홈 화면은 공유되지 않습니다. 앱 또는 Android의 화면공유 표시에서 중지하면 공유가 종료됩니다. Android 15 QPR1 이상은 화면을 잠글 때 공유를 자동으로 종료합니다. 이전 버전의 잠금 동작은 기기에서 확인해야 합니다.

이번 수정은 이전 승인·서비스·첫 프레임 응답이 취소 후의 새 방송에 적용되는 문제를 막습니다. 이전 캡처가 완전히 종료된 뒤 다음 승인을 요청하며, 오래된 방송의 중지 응답이 새 방송을 종료하지 않도록 합니다. 캡처 엔진과 고화질·60fps 요청 정책은 유지합니다.

문제가 생기면 설정의 **진단 내보내기**를 사용하세요. 기종·Android SDK·WebView 버전, 승인/서비스/첫 프레임 단계, 캡처 FPS·인코더 통계와 최근 프로세스 종료 이유를 확인할 수 있습니다. 비밀번호·토큰·SDP·ICE 후보는 진단에서 숨깁니다. 앱이 강제 종료돼 내보내기가 어렵다면 `scripts/COLLECT_ANDROID_LOGS_GIT_BASH.sh`로 소유자 컴퓨터에서 추가 로그를 수집할 수 있습니다.

Galaxy Quantum2 / Android 14를 포함한 실제 기기 시험은 별도입니다. 단위 검사·APK 컴파일 결과로 기기별 화면공유, 하드웨어 인코더, 발열·FPS·네트워크 성능이 확인됐다고 판단하지 않습니다. 특히 이전 crash·검은 화면·13fps 현상의 원인은 해당 기기의 재현 단계와 로그가 필요합니다.

최신 ARM64 휴대폰의 16 KB 페이지 지원은 실제 APK의 ELF LOAD·GNU_RELRO와 ZIP 정렬을 CI에서 검사합니다. 별도의 16 KB 기기 실행 시험도 필요합니다. 현재 WebRTC의 x86_64 RELRO 정렬 문제 때문에 x86·x86_64 에뮬레이터용 바이너리는 이번 휴대폰 APK에서 제외합니다. WebRTC 버전과 캡처 엔진은 유지합니다.

공통 화면 원본은 `shared`이며 Android assets는 `scripts/prepare_unified.py`로 생성합니다. 설치·계정 설정과 보존 범위는 [build62 사용 안내](../docs/START_BUILD62_KO.md)를, 검증 결과와 남은 확인 항목은 [build62 상태](../docs/BUILD62_STATUS_KO.md)를 확인하세요.
